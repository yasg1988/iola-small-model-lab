## Практический предел для этого ПК

Для мастера установки `iola` этот ПК нужно классифицировать так:

```text
комфортный уровень: до 2B
рабочий, но медленный уровень: 4B-7B
предельный нерабочий уровень: 12B
не предлагать: 14B и выше
```

Рабочее правило для рекомендаций:

```text
если ПК похож на этот профиль, предлагать модели строго ниже 12B;
модели 12B считать диагностическим пределом, а не рабочей рекомендацией;
для интерактивного режима по умолчанию выбирать 1B-2B;
для редких проверок можно предлагать 4B-7B с предупреждением о скорости.
```

## Что важно для MoE/Sparse

MoE-модель может активировать только часть параметров на токен, но локальный раннер все равно часто должен иметь доступ ко всем экспертам. Поэтому для домашнего ПК важны не только активные параметры, но и общий размер модели, формат квантования, RAM/VRAM и поведение конкретного раннера.

Пример: Mixtral 8x7B имеет около 46.7B общих параметров и около 12.9B активных параметров на токен по описанию Mistral AI. Это снижает вычисления на токен, но не делает модель эквивалентной 7B по памяти и диску.
