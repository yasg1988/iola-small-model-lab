# План внедрения подбора локальной модели в мастер `iola`

Этот документ фиксирует логику для будущей доработки CLI. Сейчас в код `iola-cli` это не внедряется.

## Цель

Когда пользователь в мастере выбирает установку локальной модели, CLI должен:

1. Проверить параметры ПК.
2. Проверить доступное место на диске для моделей.
3. Определить безопасный класс моделей.
4. Предложить максимальную модель, которая будет работать без зависания.
5. Отдельно показать более тяжелые модели как экспериментальные, а не рекомендуемые.

## Минимальные проверки

```text
RAM_GB = общий объем ОЗУ
FREE_MODELS_DISK_GB = свободное место на диске OLLAMA_MODELS
GPU_NAME = имя видеокарты, если есть
GPU_RAM_GB = объем VRAM, если определяется
OLLAMA_AVAILABLE = доступен ли Ollama API
```

## Черновая формула рекомендации

```text
если RAM_GB < 8:
  рекомендовать 0.6B-1B
  2B только с предупреждением

если 8 <= RAM_GB < 16:
  рекомендовать 1B-2B
  разрешить 4B как медленный режим
  7B только как эксперимент
  12B считать предельным нерабочим классом

если 16 <= RAM_GB < 32:
  рекомендовать 4B-7B
  12B как медленный режим
  14B+ только после теста

если RAM_GB >= 32:
  рекомендовать 7B-14B
  MoE/Sparse проверять отдельно по общему размеру модели и раннеру
```

## Диагностический ladder-тест

Мастер может предложить тест:

```text
1B -> 2B -> 4B -> 7B -> 12B
```

Каждый шаг:

- скачать модель только на диск моделей;
- сгенерировать короткий ответ с `num_predict=16-32`;
- замерить время до первого полного ответа;
- остановиться, если генерация дольше порога или ПК начинает подвисать.

Для текущего RedmiBook 15:

```text
1B-2B: рекомендовать
4B: разрешить
7B: разрешить как медленный режим
12B: считать пределом, не рекомендовать
14B+: не тестировать автоматически
```

## UX в мастере

Пример текста:

```text
Ваш ПК: 7.8 ГБ ОЗУ, модели хранятся на D:\ollama\models.
Рекомендуемый класс: 1B-2B.
Максимальный экспериментальный класс: 7B.
12B на похожем ПК запускался, но ответ занял несколько минут, поэтому не рекомендуется.
```

## MoE/Sparse

Для MoE нельзя выбирать модель только по активным параметрам. Нужно показывать оба числа:

```text
Qwen3-30B-A3B: 30B всего, около 3B активных
Mixtral 8x7B: 46.7B всего, около 12.9B активных
```

Правило для CLI:

```text
для скачивания и загрузки ориентироваться на общий размер и размер файла;
для скорости генерации учитывать активные параметры;
для слабых ПК MoE предлагать только после отдельного теста раннера.
```
