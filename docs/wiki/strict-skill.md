# strict-skill

## Что это

`strict-skill` - стратегия жесткого доменного скилла. Скилл получает факт и отвечает шаблоном, модель не решает, какой факт верный.

## На какие исследования опираемся

- Toolformer: [Language Models Can Teach Themselves to Use Tools](https://arxiv.org/abs/2302.04761)
- ReAct: [Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629)

## Почему взяли

Для городского CLI факт важнее красивой генерации. Если есть надежный API/MCP, модель не должна самостоятельно выбирать адрес, ИНН или руководителя.

## Гипотеза

Шаблонный скилл даст максимальную точность и минимальную задержку на структурированных данных.

## Что проверяем

- Достаточно ли правил для обычных вопросов.
- Умеет ли шаблон явно опровергать ложную предпосылку.
- Можно ли использовать как базовый режим CLI.

## Результат

| Датасет | Верно | Вывод |
| --- | ---: | --- |
| `simple-facts` | 100/100 | работает |
| `adversarial-facts` | 100/100 | работает |

## Решение

Использовать как базовый надежный режим для слоев с хорошей структурой данных.
