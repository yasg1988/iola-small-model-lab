# Блок 3. Смешанные концепции

## `skill-router`

CLI до модели определяет скилл и вызывает MCP. Модель используется только для языка.

## `memory-verified`

Поиск по условной памяти + проверяющий. Если проверяющий не подтверждает ответ, возвращается "данные не подтверждают".

## `escalation-ladder`

Лестница:

```text
0 прямой факт
1 строгий скилл
2 проверяющий
3 консилиум
4 большая локальная MoE-модель / Codex / API
```

Гипотеза: это лучший продуктовый режим, потому что он экономит ресурсы и не дает слабой модели отвечать там, где она опасна.
