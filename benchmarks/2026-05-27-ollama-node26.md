## Summary

The direct mode is not viable for current municipal facts: all tested models scored `0/10` on simple facts without external context.

The best simple-fact result was `gemma3:1b` with `mcp-context`: `9/10`, average latency about `1.75s`.

The adversarial set is still unresolved. Best strict score was only `1/10`. The model often refuses or gives a boolean-like answer without restating the correct value, so prompt-only verification is not enough. The next implementation step should be a deterministic answer composer or post-checker after model generation.
