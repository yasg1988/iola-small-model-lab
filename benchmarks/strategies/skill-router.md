# Стратегия `skill-router`

## Идея

Сначала выбирается доменный скилл и слой данных, затем вызывается API/MCP. Модель может использоваться только для формулировки, но не для выбора факта.

## Бенчмарк

| Датасет | Верно | Точность | Доля ответов | Среднее, мс |
| --- | ---: | ---: | ---: | ---: |
| `simple-facts` | 100/100 | 100.0% | 100.0% | 0.02 |
| `adversarial-facts` | 100/100 | 100.0% | 100.0% | 0.03 |

```text
simple-facts       ██████████ 100%
adversarial-facts  ██████████ 100%
```

## Вывод

Практичный рабочий режим для CLI: он хорошо масштабируется на новые слои данных и держит модель под контролем.
