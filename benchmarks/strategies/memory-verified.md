# Стратегия `memory-verified`

## Идея

Сначала используется условная память для поиска факта, затем отдельная проверка подтверждает, что ответ не повторяет ложную предпосылку.

## Бенчмарк

| Датасет | Верно | Точность | Доля ответов | Среднее, мс |
| --- | ---: | ---: | ---: | ---: |
| `simple-facts` | 100/100 | 100.0% | 100.0% | 0.03 |
| `adversarial-facts` | 100/100 | 100.0% | 100.0% | 0.06 |

```text
simple-facts       ██████████ 100%
adversarial-facts  ██████████ 100%
```

## Вывод

Закрывает главный риск `conditional-memory`: факт не просто извлекается, а сверяется перед ответом.
